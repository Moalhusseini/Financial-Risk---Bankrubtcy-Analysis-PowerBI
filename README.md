# Financial Risk Analysis & Decision Support Dashboard

## Project Overview

An interactive Power BI dashboard developed to analyze financial risk,
bankruptcy indicators, company financial performance, and risk categories.

The dashboard was designed as part of a Decision Support System (DSS)
to transform financial data and analytical results into actionable
risk-monitoring insights.

## Objectives

- Analyze financial risk indicators
- Identify companies with higher bankruptcy risk
- Explore relationships between financial indicators
- Segment companies based on financial characteristics
- Monitor risk categories and financial stability
- Support data-driven financial decision-making

## Tools

- Power BI
- Power Query
- DAX
- Data Analysis
- Data Visualization
- Machine Learning outputs
